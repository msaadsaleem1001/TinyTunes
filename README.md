🎵 TinyTunes App

TinyTunes is a safe and parent-controlled video streaming app for kids, inspired by YouTube Kids. Built with Flutter and Dart, the app allows parents to manage and control the content their children watch by selecting and adding curated YouTube videos. TinyTunes provides a secure, clean, and engaging environment where children can explore educational and entertaining videos — without exposure to unwanted content.

🚀 Features
Parent-Controlled Content
Parents can add YouTube videos manually
Only approved videos appear in the app
No open YouTube browsing

📂 Organized Categories
Videos are sorted into predefined categories (e.g., Learning, Cartoons, Rhymes, Stories, etc.)
Easy navigation for kids
Clean and colorful UI

🎬 YouTube Streaming Integration
Streams videos directly from YouTube using embedded player
No direct redirection to YouTube app
Safe viewing environment

☁ Supabase Integration
Backend powered by Supabase
Parents can: Add new videos
Manage video metadata
Assign categories
Real-time updates from database

🎵 Background Music
Soft background music plays during idle screens
Improves engagement and user experience
Automatically pauses during video playback

🎨 Kid-Friendly UI
Bright, simple, and intuitive design
Large touch-friendly buttons
Smooth animations

🛠 Tech Stack
Frontend: Flutter (Dart)
Backend: Supabase
Video Source: YouTube Embedded Player
State Management: (Bloc)
Audio Handling: Flutter audio packages

🔐 How Content Control Works
Parent logs into admin panel
Adds YouTube video URL
Selects a category
Video is stored in Supabase
Kids can browse safely within allowed content

⚙ Installation
Prerequisites
Flutter SDK (latest stable)
Dart SDK
Supabase project setup
YouTube Player Flutter package

Steps
git clone https://github.com/msaadsaleem1001/TinyTunes.git
cd TinyTunes
flutter pub get
flutter run
